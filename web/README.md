# Gundam Nexus - Frontend (PWA)

React + Vite + React Router + Axios + vite-plugin-pwa. Panduan lengkap ada di [README utama](../README.md).

```bash
npm install
cp .env.example .env   # atur VITE_API_BASE_URL
npm run dev            # pengembangan
npm run build && npm run preview   # uji mode PWA / offline
```
